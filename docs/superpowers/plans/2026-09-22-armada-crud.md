# Armada (Vehicle Fleet) CRUD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Wire up the sidebar's "Armada" menu item to a real, database-backed CRUD (list/create/update/delete) for the vehicle fleet, and wire the dashboard's fleet summary counts to that same real data.

**Architecture:** A new Django app `fleet` owns a single `Vehicle` model and its own list/create/update/delete views, URLs (namespaced `fleet:`, mounted at `/armada/`), and templates (extending the existing `base.html` layout). `accounts/views.py::dashboard_view` gains a read-only cross-app import of `fleet.models.Vehicle` to replace its hardcoded `fleet_summary` dict with a real aggregate query.

**Tech Stack:** Django 6.1 (function-based views, `ModelForm`), the project's existing sqlite/Postgres-per-environment DB (whichever `DATABASES` in `harwat_main/settings.py` currently points at — this plan adds one app-agnostic model, no environment-specific SQL), Tailwind CSS (existing utility classes, matching `accounts/forms.py`'s style), the dev Podman stack (`podman_app_1` container) for running tests and migrations.

**Spec:** `docs/superpowers/specs/2026-09-22-armada-crud-design.md`

## Global Constraints

- New app name: `fleet` (not `accounts` — different domain, per spec).
- Full CRUD (list, create, update, delete) — not read-only.
- Model fields, exact names and types: `nopol` (unique), `jenis` (choices), `merek`, `tahun`, `status` (choices), `odometer_km`, `penanggung_jawab` — no `created_at`/`updated_at`, no other fields.
- Function-based views only, `@login_required` on every view — matches `accounts/views.py`'s existing convention, no class-based views.
- No pagination, search, sort, soft-delete, file upload, or JSON API — explicitly out of scope per spec.
- `templates/base.html`'s Jadwal/Servis/Laporan sidebar links stay `href="#"` — untouched, separate future work.
- `upcoming_maintenance` and `overdue_alerts` in `accounts/views.py::dashboard_view` stay hardcoded — only `fleet_summary` changes.
- Run tests via `podman exec podman_app_1 python manage.py test <app>` — the dev stack's `app` container (confirmed running, bind-mounts the repo live, no rebuild needed between steps).
- Every step's test command: run from repo root.

```python
from django.db import models


class Vehicle(models.Model):
    class Jenis(models.TextChoices):
        TRUK = "truk", "Truk"
        JEEP = "jeep", "Jeep"
        MOTOR = "motor", "Motor"
        AMBULANS = "ambulans", "Ambulans"
        MOBIL = "mobil", "Mobil"
        LAINNYA = "lainnya", "Lainnya"

    class Status(models.TextChoices):
        SIAP_PAKAI = "siap_pakai", "Siap Pakai"
        DALAM_PERBAIKAN = "dalam_perbaikan", "Dalam Perbaikan"
        PERLU_SERVIS = "perlu_servis", "Perlu Servis"

    nopol = models.CharField(max_length=20, unique=True, verbose_name="Nomor Polisi")
    jenis = models.CharField(max_length=20, choices=Jenis.choices)
    merek = models.CharField(max_length=100, verbose_name="Merek/Model")
    tahun = models.PositiveSmallIntegerField(verbose_name="Tahun")
    status = models.CharField(max_length=20, choices=Status.choices, default=Status.SIAP_PAKAI)
    odometer_km = models.PositiveIntegerField(default=0, verbose_name="Odometer (KM)")
    penanggung_jawab = models.CharField(max_length=150, verbose_name="Penanggung Jawab")

    class Meta:
        ordering = ["nopol"]

    def __str__(self):
        return self.nopol
```

```python
    "w-full rounded-md border border-slate-300 bg-white px-3 py-2 text-sm "
    "text-slate-900 shadow-sm placeholder:text-slate-400 focus:border-gold "
    "focus:outline-none focus:ring-2 focus:ring-gold/40"

SELECT_CLASSES = (
    "w-full rounded-md border border-slate-300 bg-white px-3 py-2 text-sm "
    "text-slate-900 shadow-sm focus:border-gold focus:outline-none "
    "focus:ring-2 focus:ring-gold/40"

SELECT_FIELD_NAMES = {"jenis", "status"}


class VehicleForm(forms.ModelForm):
    class Meta:
        model = Vehicle
        fields = ["nopol", "jenis", "merek", "tahun", "status", "odometer_km", "penanggung_jawab"]

    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        for name, field in self.fields.items():
            field.widget.attrs["class"] = (
                SELECT_CLASSES if name in SELECT_FIELD_NAMES else TEXT_INPUT_CLASSES
            )
        self.fields["nopol"].widget.attrs["placeholder"] = "B 9021 XY"
```

In `fleet/views.py`, add the import and view:

```python
from django.contrib.auth.decorators import login_required
from django.shortcuts import redirect, render

from .forms import VehicleForm
from .models import Vehicle


@login_required
def vehicle_list(request):
    vehicles = Vehicle.objects.all()
    return render(request, "fleet/vehicle_list.html", {"vehicles": vehicles})


@login_required
def vehicle_create(request):
    if request.method == "POST":
        form = VehicleForm(request.POST)
        if form.is_valid():
            form.save()
            return redirect("fleet:vehicle_list")
    else:
        form = VehicleForm()
    return render(request, "fleet/vehicle_form.html", {"form": form, "is_edit": False})
```
